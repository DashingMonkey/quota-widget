# Kimi Code Plan

[返回首页](../../README.md) · [供应商目录](README.md)

## 查询内容

- 频率窗口额度，例如 5 小时窗口。
- 周额度与重置时间。
- 会员等级。

额度窗口的名称和时长以接口返回为准。本供应商查询 Kimi Code Plan，不查询通用模型 API 的钱包余额。

## 配置步骤

1. 打开 **设置 → 供应商 → ＋ 添加供应商**，选择「Kimi Code Plan」。
2. 填写对应 Code Plan 账户的 API Key。
3. 选择图标或显示名称、刷新间隔，点击 **确认**。

## 查询失败时

确认使用的是 Kimi Code Plan 的 Key，且对应账户已有可用套餐。凭证失效后在供应商编辑窗口替换 Key，再测试连接。
