# DeepSeek

[返回首页](../../README.md) · [供应商目录](README.md)

## 查询内容

- 总余额。
- 充值余额与赠送余额。
- 账户可用状态。

悬浮窗直接显示金额，详情面板列出余额组成。金额及币种以接口返回为准，不展示套餐百分比或重置倒计时。

## 配置步骤

1. 打开 **设置 → 供应商 → ＋ 添加供应商**，选择「DeepSeek」。
2. 填写对应账户的 API Key。
3. 选择图标或显示名称、刷新间隔，点击 **确认**。

## 查询失败时

确认 Key 有效且属于需要查询的账户；必要时在供应商编辑窗口替换 Key。连接正常但余额为零时，请在对应账户中核对余额。
