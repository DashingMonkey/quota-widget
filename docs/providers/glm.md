## 查询内容

| 类型 | 展示内容 | 凭证 |
| --- | --- | --- |
| Coding Plan 个人套餐 | 5 小时窗口、周额度、会员等级与重置时间 | Coding Plan Key |
| Coding Plan 团队套餐 | 团队额度、会员等级与重置时间 | Coding Plan Key、组织 ID、项目 ID |
| 人民币钱包 | 可用余额与累计充值、赠送、消费 | 标准 API Key |
| 美元钱包 | 同上，使用美元单位 | 标准 API Key |

只显示接口返回的额度项目。独立的 Token 资源包暂不纳入钱包统计。

## 配置步骤

1. 打开 **设置 → 供应商 → ＋ 添加供应商**，选择「GLM 国内版」或「GLM 国际版」。
2. 填写所需产品对应的 API Key。
3. 在 **查询内容** 中选择「Coding Plan 套餐」「钱包余额（¥ 人民币）」或「钱包余额（$ 美元）」。
4. 查询套餐时，选择「个人版」或「团队版」；团队版还需填写组织 ID 与项目 ID。
5. 选择图标或显示名称、刷新间隔，点击 **确认**。

需要同时查看套餐和钱包时，添加两条 GLM 配置，分别填写对应的 Key。

## 团队 ID 从哪里获取

在控制台打开 Coding Plan 页面，按 F12 打开开发者工具，在 Network 中找到 `api/monitor/usage/quota/limit` 请求，复制请求头中的：

- `bigmodel-organization`：组织 ID。
- `bigmodel-project`：项目 ID。

## 币种与地区

钱包币种应与账户一致，程序不会进行汇率换算。人民币钱包使用国内站点，美元钱包使用国际站点；「国内版 / 国际版」选项只影响 Coding Plan 查询。

## 查询失败时

先确认 Key 属于所选产品。团队版还需检查组织和项目 ID，钱包金额或单位不符时检查币种选择。
钱包使用控制台内部接口，接口调整后可能需要更新程序。
