# Claude Pro / Max

## 查询内容

5 小时窗口、周额度与重置时间。悬浮窗和详情进度条以剩余额度展示。

本供应商查询订阅账户用量，不查询按量计费的 API 钱包余额。具体额度窗口以账户接口返回为准。

## 使用本机登录凭证

1. 先在本机 Claude Code 中登录订阅账户。
2. 打开 **设置 → 供应商 → ＋ 添加供应商**，选择「Claude Pro/Max」。
3. 将 **API Key** 输入框留空，选择显示方式和刷新间隔，点击 **确认**。

程序会读取 `%USERPROFILE%\.claude\.credentials.json` 中的访问令牌，不修改该文件。

## 手动填写令牌

也可以在 **API Key** 输入框填写对应账户的访问令牌，如 `sk-ant-oat01-...`。此处需要登录访问令牌，普通模型调用 API Key 不能替代。

## 刷新与凭证失效

为减少服务端限流，有效刷新间隔至少约为 180 秒。设置更短间隔或双击刷新时，仍遵守冷却限制。

若提示本机凭证不存在或已过期，请先在 Claude Code 中重新登录，再刷新额度；手动填写的令牌需要自行替换。查询使用未公开的登录用量接口，接口调整后可能需要更新程序。
