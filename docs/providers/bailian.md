# 百炼 Token Plan

[返回首页](../../README.md) · [供应商目录](README.md)

## 查询内容

本月、7 天或 5 小时账期的额度比例与重置时间，以及可获取的套餐档位和 Credits 总量。只展示接口实际返回的窗口；无法获取总量时仅展示百分比。

本供应商查询百炼 Token Plan，不查询阿里云账户的通用钱包余额。

## 自动获取 Cookie

使用控制台 Cookie 查询，不能用模型调用的 API Key 代替。自动获取需要 Microsoft Edge 或 Google Chrome。

1. 打开 **设置 → 供应商 → ＋ 添加供应商**，选择「百炼 Token Plan」。
2. 点击「登录 Cookie」旁的 **自动获取**。已有 Cookie 有效时直接复用，否则打开独立登录窗口。
3. 登录对应的阿里云账户，验证成功后 Cookie 自动填入编辑框。
4. 选择显示方式和刷新间隔，点击 **确认**。

登录入口为 `https://bailian.console.aliyun.com/`。

## 手动填写与多账户

登录控制台，在浏览器开发者工具的 Network 面板中找到额度查询请求，复制 Cookie 请求头。支持粘贴带 `Cookie:` 前缀的整行内容。

百炼与千问共用独立的登录浏览器配置，通常可复用登录状态；每条供应商分别保存 Cookie。「自动获取」优先使用浏览器当前账号，暂未提供单独的切换账号入口。添加其他账户时，新建供应商并手动粘贴该账户 Cookie。

## 获取中切换与常见提示

- 切换供应商或关闭编辑框，会取消旧获取并关闭对应登录窗口，旧结果不会回填。
- Cookie 失效时，重新点击「自动获取」登录。
- 未返回可用套餐数据时，显示「该账号未开通 Token Plan」。若已开通，请核对当前登录账户并重新获取 Cookie。

查询使用控制台内部接口，接口调整后可能需要更新程序。
