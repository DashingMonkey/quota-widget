## 查询内容

| 查询类型 | 展示内容 |
| --- | --- |
| Token Plan 套餐 | 月度 Credits、已用与剩余比例、重置时间；有补偿额度时单独展示 |
| 账号余额 | 总余额，以及接口返回的现金 / 赠送余额 |

需要同时查看套餐和余额时，添加两条 MiMo 配置并分别选择查询类型。

## 自动获取 Cookie

MiMo 使用控制台 Cookie 查询，不能用模型调用的 API Key 代替。自动获取需要 Microsoft Edge 或 Google Chrome。

1. 打开 **设置 → 供应商 → ＋ 添加供应商**，选择「小米 MiMo」。
2. 点击「登录 Cookie」旁的 **自动获取**。已有 Cookie 有效时直接复用，否则打开独立的浏览器窗口。
3. 在打开的窗口中登录小米账户，验证成功后 Cookie 自动填入编辑框。
4. 在 **查询内容** 中选择「Token Plan 套餐」或「账号余额」。
5. 选择显示方式和刷新间隔，点击 **确认**。

登录入口为 `https://platform.xiaomimimo.com/console/balance`。

## 手动填写与多账户

登录对应控制台，打开浏览器开发者工具的 Network 面板，在 `api/v1` 额度或余额请求中复制 Cookie 请求头。支持粘贴带 `Cookie:` 前缀的整行内容。

每条供应商单独保存 Cookie。「自动获取」会复用登录浏览器中的已有账户；添加其他账户时，可新建供应商并手动粘贴该账户 Cookie。

## 获取中切换与常见提示

- 切换供应商或关闭编辑框，会取消旧获取并关闭对应登录窗口，旧结果不会回填。
- Cookie 失效时，重新点击「自动获取」登录。
- 未返回可用套餐数据时，显示「该账号未开通 Token Plan」。先确认控制台里的账户与套餐状态；只需查看余额时改选「账号余额」。

查询使用控制台内部接口，接口调整后可能需要更新程序。
