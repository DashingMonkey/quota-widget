# 供应商配置

[返回首页](../../README.md) · [文档目录](../README.md)

在 **设置 → 供应商 → ＋ 添加供应商** 中选择服务商。每条供应商分别保存凭证、显示方式和刷新间隔；同一家可添加多条配置。

| 供应商 | 配置文档 |
| --- | --- |
| GLM（国内 / 国际） | [套餐、团队配置与钱包余额](glm.md) |
| MiniMax（国内 / 国际） | [套餐额度与周加成](minimax.md) |
| Kimi Code Plan | [频率窗口与周额度](kimi.md) |
| DeepSeek | [总余额、充值与赠送余额](deepseek.md) |
| Claude Pro / Max | [本机凭证与订阅额度](claude.md) |
| Codex（ChatGPT 套餐） | [本机凭证与订阅额度](codex.md) |
| 小米 MiMo | [Cookie 登录、Token Plan 与余额](mimo.md) |
| 千问 Token Plan | [Cookie 登录与账期额度](qwen.md) |
| 百炼 Token Plan | [Cookie 登录与账期额度](bailian.md) |
| 自定义接口 | [请求配置与额度规则](../custom-api.md) |

各文档描述本程序可读取和显示的内容，实际额度以对应账户和接口返回为准。界面只展示有数据的项目，不补算缺失的额度窗口或重置时间。
