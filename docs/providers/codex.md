# Codex（ChatGPT 套餐）

[返回首页](../../README.md) · [供应商目录](README.md)

## 查询内容

- 5 小时窗口与周额度。
- 重置时间与套餐档位。

悬浮窗和详情进度条以剩余额度展示，具体额度窗口以账户接口返回为准。本供应商查询 ChatGPT 套餐用量，不查询 API 余额。

## 使用本机登录凭证

1. 先在本机 Codex 中使用 ChatGPT 套餐账户登录。
2. 打开 **设置 → 供应商 → ＋ 添加供应商**，选择「Codex (ChatGPT 套餐)」。
3. 将 **API Key** 输入框留空，选择显示方式和刷新间隔，点击 **确认**。

程序会读取 `%USERPROFILE%\.codex\auth.json` 中的访问令牌，不修改该文件。该文件需要包含 ChatGPT 套餐登录凭证；仅使用 API Key 模式时无法读取对应套餐额度。

## 手动填写令牌

也可以在 **API Key** 输入框填写对应账户的 ChatGPT 访问令牌。普通模型调用 API Key 不能替代登录访问令牌。

## 查询失败时

若提示凭证文件不存在、没有访问令牌或凭证过期，请在本机 Codex 中重新登录 ChatGPT 账户，再刷新额度；手动填写的令牌需要自行替换。

查询使用未公开的登录用量接口，接口调整后可能需要更新程序。
