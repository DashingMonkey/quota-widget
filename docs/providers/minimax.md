## 查询内容

- 5 小时窗口额度与重置时间。
- 周额度与周加成。
- 接口按模型返回多个额度项时，分别展示对应项目。

本供应商查询套餐额度，不提供账户钱包余额。实际显示项以接口返回为准。

## 配置步骤

1. 打开 **设置 → 供应商 → ＋ 添加供应商**。
2. 按账户所属站点选择「MiniMax 国内版」或「MiniMax 国际版」。
3. 填写可用于该账户套餐查询的 API Key。
4. 选择图标或显示名称、刷新间隔，点击 **确认**。

有多个账户或同时使用国内、国际站点时，分别添加配置。

## 查询失败时

确认 Key 所属账户、站点与套餐一致。国内版使用 `minimaxi.com`，国际版使用 `minimax.io`；选错区域可能无法验证凭证。接口没有返回的周额度或加成不会额外补算。
