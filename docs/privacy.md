# 数据与隐私

[返回首页](../README.md) · [文档目录](README.md)

- 配置保存在 `%LOCALAPPDATA%\QuotaWidget\config.json`，可通过 **设置 → 关于 → 打开配置目录** 定位。
- API Key、Cookie，以及自定义接口的请求头与请求体使用 Windows DPAPI 加密保存，绑定当前电脑与 Windows 用户。更换电脑或账户后，需要重新填写凭证。
- 自动登录使用独立的浏览器配置目录。额度查询连接相应服务商或你配置的自定义接口，检查更新连接本项目的发布源。
- 请勿分享配置文件或包含凭证的截图；反馈问题时先遮盖 Key、Cookie、令牌与账户信息。
