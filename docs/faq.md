# 常见问题

[返回首页](../README.md) · [文档目录](README.md)

<details>
<summary><strong>刷新间隔在哪里设置？为什么没有立即请求？</strong></summary>

在 **设置 → 供应商** 顶部调整「通用刷新间隔」，默认 60 秒。添加或编辑供应商时，也可以选择独立间隔，默认「跟随通用」。

修改间隔后保留当前额度，并按新间隔重新计时。接口限流、冷却时间以及 Claude 的最小刷新间隔仍然生效，双击刷新也不会绕过这些限制。

</details>

<details>
<summary><strong>悬浮窗不见了，怎么找回来？</strong></summary>

如果只是吸附收起，单击系统托盘图标会临时展开约 2 秒；鼠标移入后即可继续操作。

如果已关闭悬浮窗，右键托盘图标并选择「开启悬浮窗」。关闭悬浮窗不会退出程序，也不会停止后台刷新；需要完全退出时，请使用右键菜单的退出项。

</details>

<details>
<summary><strong>升级后需要重新配置吗？</strong></summary>

同一电脑、同一 Windows 账户下，替换程序后会继续使用本地配置。旧版本位于程序旁的 `config.json` 会在启动时自动迁移到新的配置目录。

旧版置顶栏已统一为悬浮窗，原有供应商、排列与悬浮窗位置会保留。

</details>

## 某家供应商查询失败

先确认使用的是该服务商支持的凭证类型、地区与查询内容，再在设置中测试连接。
各家的凭证要求和错误处理见[供应商配置](providers/README.md)。部分套餐查询使用未公开接口，服务商调整接口后可能需要更新程序。

反馈问题时，请附上版本、供应商类型、复现步骤和错误提示，并遮盖 API Key、Cookie、令牌和账户信息。
