# QuotaWidget · AI 额度工具

在桌面集中查看 AI 套餐额度与账户余额。<br>
贴边收起，悬停展开，支持深浅主题与自定义接口。<br>
使用 C# 与 WinForms 开发的 Windows 原生应用，免安装运行。
